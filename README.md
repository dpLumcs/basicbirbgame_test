# Doodle Bird
 
A simple Flappy Bird-style game built with Flutter.

- (this is a test project)
- (Claude one shot)
 
## Features
- Tap (or press Space) to flap and fly through the pipes
- Pause and resume, with a top-left menu button (Pause / Resume / Back to Menu)
- Score, best score, and run history saved on the device
- Runs on Android, iOS, and web
## Controls
| Action | Mobile | Desktop |
|---|---|---|
| Flap | Tap | Space / click |
| Pause / resume | Top-left button | P |
| Back to menu | Top-left button | Esc |
